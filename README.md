## 🚀 Getting Started

Want to explore or run the project locally?

### 📋 Prerequisites

- A modern web browser.
- Visual Studio Code (recommended).
- Live Server extension (recommended).

### ⚙️ Installation

**1. Clone the repository:**

```bash
git clone https://github.com/theHaranXer/Project-Spark-Plus.git
```

**2. Navigate to the project directory:**

```bash
cd Project-Spark-Plus
```

**3. Open the folder in VS Code.**

**4. Open `Index.HTML`.**

**5. Launch the project using Live Server.**

Alternatively, run a local Python server:

```bash
python -m http.server 8000
```

Visit `http://localhost:8000/Index.HTML` in your browser.
